# Accessibility audit summary

Generated by `frontend/a11y/summarize.mjs` from the raw JSON in `before/` and `after/`. Every figure below is read from tool output; none is estimated.

**How to read it.** *axe* counts are `rules / affected elements` per severity (critical · serious · moderate · minor), limited to the WCAG 2.0/2.1 A and AA rule tags. *Lighthouse* is the accessibility category score (0 to 100) with the number of failed audits; it reports no severity levels, so none is shown for it. States that need a click first (open dialogs, expanded rows, the mobile drawer) are checked with axe only, because Lighthouse's navigation mode cannot open them. Layout columns come from a small custom script (`a11y/audit.mjs`), not from axe or Lighthouse.

Tools: Lighthouse 13.6.0, axe-core 4.14.0, Playwright 1.65.0, Chromium 151.0.7922.34. Target: production build served locally against the local API with the synthetic demo data.
